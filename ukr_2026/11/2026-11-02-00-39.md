Herdr вийшов десктопом, вже не просто "tmux для агентів"

**Herdr — runtime для кодових агентів,**
https://herdr.dev/tui/
Herdr це runtime для кодових агентів, який не тільки обгортає Claude Code, Codex, OpenCode чи Pi, а володіє їхніми терміналами. Класичний Herdr не зникає, але це тепер окремий продукт зі своїм сервером: агенти, запущені в TUI, не видно в застосунку, і навпаки. 

https://herdr.dev/
29 жовтня Herdr анонсував одразу дві речі: новий **herdr-core** і нативний десктопний застосунок на ньому. Агенти живуть у `herdr-core`, маленькому сервері на машині, тому закриття вікна, оновлення не вбивають роботу. Агенти можуть керувати іншими агентами. Після рестарту `herdr-core` процеси не відновлюються, тільки layout. 

Herdr цікавий тим, що робить UI файлами й дає агентам керувати один одним. Це вже не «tmux зі статусами», а спроба зробити робоче середовище, яке агент може переписати під себе. Телеметрія в релізах увімкнена за замовчуванням (Settings → Privacy).

Layout це не теми, а повноцінні вікна зі своєю логікою. У комплекті вже є **Herdr 98**. Спільнота викладає свої layout'и: **Pasture** (агенти як вівці, blocked стрибає з бульбашкою), **Mission** (зелений mission control), **Board** (картки needs you / working / done / idle), **Call**, **Threads**.  Важливо, що чужий layout може читати файли, ходити в мережу й запускати процеси.

**Швидкий тур** 
показує, що десктоп — не просто красивий TUI, а конструктор. Світла тема, перенос старих налаштувань TUI, додавання file tree mod'а ще на setup, відкриття space. 

[https://www.youtube.com/watch?v=6GR75W2dRmU](https://www.youtube.com/watch?v=6GR75W2dRmU)

![YouTube Preview](https://img.youtube.com/vi/6GR75W2dRmU/sddefault.jpg)

Автор показує, що mods можна ставити одразу. Можна попросити Herdr перемкнути на tmux-біндинги. Автор каже агенту: «split panel vertically and start two Codex agents; add another tab with two Claude agents» — агент сам робить спліт, відкриває таб і запускає агентів. Агенти спілкуються через міст; lead agent делегує worker'ам; можна сортувати за пріоритетом/space, перетягувати панелі, робити горизонтальні/вертикальні спліти.

**Обговорення**
https://news.ycombinator.com/item?id=50298436
«harness for your harnesses» який не схожий на вайбкодед-слоп. Зручний «everything is a pane», тобто можна тримати SSH-сесію в одному пейні, а агента в іншому просити діагностувати систему, і він не тягне ваші SSH-ключі в харнес; агенти різних вендорів можуть рев'юити один одного; кастомізація UI  «сказав додати фічу, воно перезавантажилось».

Критика: TUI і app фрагментовані, старі сесії не підхопились, keybinds інші; немає вбудованого браузера; на Windows немає нормального інсталятора/деінсталятора; у когось застосунок не побачив Claude Code або після рестарту дав порожні панелі.
