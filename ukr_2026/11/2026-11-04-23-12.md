Харнес як конструктор: Claude Code Mods, dsh Creator Mode

**Claude Code mods**
https://claude.com/blog/claude-code-mods
Працює в CLI, Code-табі десктопного застосунку і (частково) VS Code. Anthropic випустив mods 1 жовтня 2026. Mod це плагін, усередині якого лежать JS/TS-хендлер подій, це вже не «конфігурація агента» (бо кого тепре цим здивуєшь), а програмування його харнеса.  Мод можна попросити Claude Code написати з hot reload у поточній сесії - агент редагує свій же **інтерфейс**.

Claude Code викликає їх на tool call, перед відправкою промпта, під час рефрешу UI, на команду, на старт сесії. Мод живе **всередині** процесу Claude Code (з точки зору безпеки отримає всі права!), а не як окремий shell-скрипт бо старі hooks працювали ззовні й тому не могли намалювати UI. Частину коду відкрито в https://github.com/anthropics/claude-code/tree/main/mods. 

[https://www.youtube.com/watch?v=uizaxuzgEAk](https://www.youtube.com/watch?v=uizaxuzgEAk)

![YouTube Preview](https://img.youtube.com/vi/uizaxuzgEAk/sddefault.jpg)

Що це дає практично:
- переписати промпт до моделі;
- заблокувати, змінити або повторити tool call;
- схвалити чи відхилити permission request;
- вирізати секрети з tool output до того, як їх побачить модель;
- намалювати панель, смугу над промптом, кнопки, поля, select, SVG, навіть ігрове поле;
- замінити частину власного UI Claude Code — рядок tool call, спінер, діалог питання.

Деякі штатні фічі Claude Code тепер теж mods. Наприклад, `/diff` — це мод, його можна вимкнути або замінити своїм. Підтримка `AGENTS.md`, `sec-default`, телеметрія — теж. 

Які є офіційні приклади: **Token Weather** прогноз заповнення контекстного вікна; **Blast Radius** затримає небезпечну команду на кшталт `rm -rf` або force push; **Replay Theater** `/replay` як покроково показує диффи редагувань за останній хід. 

Каталоги від інших людей - https://mods4claude.com/ та https://mods.aidojo.si/  але треба пам'ятати про безпеку.

**DeepSeek Harness Creator Mode**
https://www.deepseek.com/en/harness/
2 листопада DeepSeek публічно показав Creator Mode у DeepSeek Harness (dsh)  як публічний запуск: «Your Harness. You Define It.» Як я вже писав, Creator Mode існував у preview раніше, але без підкреслення його можливостей. У вересні плагіни переїхали у постійний **Plugin Manager**, а далі з'явився пункт «Let Agent create a plugin». 

[https://www.youtube.com/watch?v=VKmUC5ukfqU](https://www.youtube.com/watch?v=VKmUC5ukfqU)

![YouTube Preview](https://img.youtube.com/vi/VKmUC5ukfqU/sddefault.jpg)

В **рекламі** показані різні шляхи модифікувати функціональні аспекти UI: галерея пам'яток, інтерактивна 3D-візуалізація Transformer, піксельна тема для всього застосунку, робоче місце для постерів, відеоредактор, плаваюче меню для виділеного тексту й плагін статистики розмови. Промти поклали тут https://cdn.deepseek.com/harness/dsh-creator-mode-prompt-collection-en.html.
