**Блок по регіону**
Логін з Muse Code через браузер впирається в `Not available in your region — The Model API isn't available in your region right now`. Окремого списку валідних країн в доках я не знайшов, але виходить Україна зараз заблокована для Model API і Muse Code напряму не залогінитись. 

**Видалення Muse Code**
https://github.com/TerryZH/muse-code-uninstaller
Неофіційний MIT-деінсталятор під macOS і Linux на Bash. За замовчуванням тільки dry-run та рахує скільки місця звільниться. Видаляє тільки з прапором `--uninstall`, батьківський `~/.local/bin` не чіпає. На Windows штатного запису в «Встановлення та видалення» при цьому нема, інсталятор пише себе в User PATH, плюс створює пісочних юзерів `muse-sbx-r1` / `u1` і групу `MuseSandboxUsers`, профілі в `C:\Users\muse-sbx-*` і ключі в `ProfileList` — після видалення все це лишається руками чистити через `takeown /f "C:\Users\muse-sbx-r1" /r /d y`.
