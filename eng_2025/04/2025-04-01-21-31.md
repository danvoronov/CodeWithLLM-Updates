Developers of the [Zed](https://zed.dev/) editor, the same ones who haven't been able to buy a Windows computer for a year to build a version for this OS, noticed that their **Zed AI** hasn't even been released yet, but it's already outdated.

Therefore, they started to enable [Agentic Editing](https://zed.dev/ai/agent) for their beta testers - judging by the description, it will be like in others: it will edit code itself, has chat profiles, a `rules` file with system instructions, model switching, and not only from Anthropic, using MCP. They also promise checkpoints - currently, in beta, this is done through git.

Importantly, this could become a good alternative to the dominance of VS Code and its forks. As soon as they can buy themselves a Windows computer. In the meantime, Zed can be [installed via Scoop](https://scoop.sh/#/apps?q=zed).
