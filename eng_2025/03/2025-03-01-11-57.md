**bolt.diy** has released [version v0.0.7](https://github.com/stackblitz-labs/bolt.diy/releases) — better support for thinking models, better UI for settings, and netlify one-click deploy.

Inception Labs has released **Mercury Coder**, an interesting new language model that uses *diffusion* technique for faster *text* generation: unlike traditional models that create text word by word, diffusion models generate entire responses simultaneously, refining them from an initially masked state to coherent text. ([news](https://www.inceptionlabs.ai/news)) — in [their chat](https://chat.inceptionlabs.ai/) it works really fast, for HTML it can display results immediately.
