Anthropic paid well-known Canadian tech blogger Tim Ruscica to make this tutorial.

**The YouTube channel Tech With Tim** (@TechWithTim) breaks down the setup and capabilities of Claude Code (mostly the desktop app): from installation and model selection to skills, subagents, hooks, and context management. The sections on MCP, plugins, mods, and routines are superficial. CLI/CI, team practices, and security are barely covered. There were already similar **"from zero to workflow" videos** about Codex (14.07.2026) and Cursor 3.0 (29.07.2026), and a year ago about Cursor 2.0, Windsurf, and Trae.

Main topics if you want to revisit the basics:

1. **Plan Mode (12:43)** — plan and questions first, then code. Reduces rework and token spend.
2. **CLAUDE.md (16:57)** — the file records the stack, commands, conventions, and restrictions; any new chat is up to speed immediately.
3. **settings.json (23:31)** — allow/ask/deny for commands and files; a mandatory `deny` for secrets.
4. **Skills (27:03)** — turns repeated explanations into reusable instructions.
5. **Subagents (31:27)** — isolate background work from the main context; can run in parallel.
6. **Hooks (35:49)** — event-driven automation: tests after a response, blocking dangerous commands, notifications.
7. **Managing Context (40:20)** — understanding the context window and `/compact` directly affects quality and cost.
