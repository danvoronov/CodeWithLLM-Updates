The VibeWise plugin makes the agent first ask how you understand the task

**VibeWise**
https://github.com/nykooi1/vibe-wise
https://www.youtube.com/watch?v=GckkaKEQ3vo
The project appeared on September 29, 2026. In a month — almost 4 thousand stars. It's a plugin for Claude Code and Codex. In Claude Code it installs from the Anthropic directory, in Codex — via the plugin marketplace. After a restart you have to explicitly enable the mode: `/vibe-wise:learn` or `$vibe-wise:learn`. Without that, the installation teaches nothing and gives no permission to code.

The agent asks how **you** propose to solve the task. Not "which stack should we use?", but "what happens to a shared note if you delete the folder?". The key part is three types of checkpoints:

- **Build** — you and the agent work out how to approach the problem.
- **Design** — you lock in the design. "Confirm and continue" records the decision and continues planning, but there's no code yet.
- **Implementation** — you separately confirm a specific change. "Implement this step" lets the agent write code.

After implementation the agent must briefly explain what changed, how the key code works, why it matches your decision, which tests were added and what they cover. Not "done", but a report you can verify.

State lives in `.vibe-wise/`: `profile.md`, `progress.md`, `project-map.md`. There are beginner / intermediate / advanced levels and a separate checkpoint frequency light / normal / frequent. There's no backend, separate model, or telemetry. The notes go into the agent's context, so the host's usual privacy settings apply here too. `.vibe-wise/` can be added to `.gitignore`.

VibeWise's methodology currently has no research proving it improves understanding in the long run. It's interesting because it makes learning a blocker for generation. That doesn't guarantee understanding, but it changes the default: the agent can no longer start with generation.

**Universal fork for other harnesses**
https://github.com/Itskorrah/vibe-wise-universal
This is not an official upstream branch, but a separate derived project. It preserves the original's authorship and demos but covers Claude Code, Codex, OpenCode V1/V2, Antigravity and portable mode. Shared notes live in the same `.vibe-wise/profile.md`, `progress.md`, `project-map.md`.

- **vibe-wise-agy**. https://github.com/adith-p/vibe-wise-agy An Antigravity port with a design-first approach.
- **vijayamukesh13j/vibe-wise** https://github.com/vijayamukesh13j/vibe-wise Another Antigravity port.
- **vibe-wise-pi** https://github.com/Aitbytes/vibe-wise-pi A port for the pi coding agent.
- **vibe-wise-mcp** https://github.com/yava-code/vibe-wise-mcp
MCP server: the same design-first gate for any agent, decisions in `.vibe-wise/`

Similar in idea, but different:

**DshVibeLearning**
https://github.com/EarzuChan/DshVibeLearning
A plugin for DeepSeek Harness: `/learn`, plans, FSRS, notes. An early POC, not a finished product.

**vibe-learn**
https://github.com/rudrasatani13/vibe-learn
A Claude Code skill: explains concepts at the moment of generation, then unobtrusive quizzes. There's a Learn block, Bug class and Mental model, spaced repetition, export to Anki/CSV/Markdown, state in `.vibe-learn/`.

**stay-sharp**
https://github.com/zhinit/stay-sharp
A CLI with manual exercises while the agent does the task. A simple idea: don't watch the agent write, write yourself in parallel.
