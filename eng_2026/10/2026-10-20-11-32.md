Which companies build both their own model and their own harness for it.

**USA**

**Anthropic — Claude Code**
https://code.claude.com/docs/en/overview
https://claude.com/pricing
One of the best-known tandems: **Claude Opus / Sonnet / Haiku** (now also Fable) plus the **Claude Code** harness (initially CLI, now IDE, desktop, web). There is no free tier for Code — the minimum is Pro at **$20/mo** ($17 with annual billing). Then **Max 5x** at $100 and **Max 20x** at $200. From a lightweight terminal client, Claude Code has grown over the years into a heavy combine with everything imaginable — Slack, Chrome, CI/CD, a mobile app, and computer use that clicks around the screen by itself. Only Anthropic models.

Anthropic has **saved limit resets**: they can be applied later, once the limit is already exhausted. Unlike Codex, such a reset restores only the limit named in the offer (the five-hour or the weekly one) and does not shift the usual weekly reset day. The first such resets came with Opus 5.5 on September 22, 2026: Pro, Max, and Team could apply them until October 22.

**OpenAI — Codex**
https://developers.openai.com/codex/cli
https://developers.openai.com/codex/pricing
**GPT** models and the agentic **Codex** harness — CLI, IDE, desktop, and cloud. OpenAI fell behind competitors in agentic coding, but was catching up: in the first months after launch it gave away a lot of tokens even on the free plan. Over the past year the CLI has evolved noticeably: multi-agent scenarios, worktrees, web search, MCP, voice input, and CI/CD integrations.

Codex *temporarily* comes with all ChatGPT subscriptions: Free (usually only the base model) and **Go $8**. Of course it is included in **Plus $20**, **Pro $100, $200, $500**. Together with the desktop app and the cloud, Codex has become one of the main competitors to Claude Code and Cursor. Only OpenAI models.

A separate Codex mechanic is the **banked reset**: a saved reset you can stockpile and apply manually once the weekly limit of your subscription plan is exhausted. It immediately refreshes both the five-hour and weekly windows and shifts the date of the next weekly reset. This is not the same as a paid reset, which you can buy after hitting the weekly limit.

**Google — Antigravity**
https://antigravity.google/
https://antigravity.google/pricing
**Gemini** lives in the **Antigravity** ecosystem: the desktop app, CLI, and IDE integrations. Before that, the open-source **Gemini CLI** was shut down for regular users on June 18, 2026, and everyone was moved to **Antigravity CLI**, which is not open source and is also a rather rough, inconvenient product. The community is still angry that contributions to the open project went into a closed product and into the fork for China's Qwen Code. Gemini 4 Argon is definitely available on **Ultra** ($100 and $200), while Free gets Gemini 3.8 Flash. The **AI Pro $20** plan is a question mark — it's all muddled as to whether Gemini 4 is there now. Also, besides Gemini, there are for some reason two old Anthropic models and OpenAI's `gpt-oss-120b`.

**Meta — Muse Code**
https://dev.meta.ai/products/muse-code/
Over the past weeks Meta has made good progress and introduced the terminal harness **Muse Code** for the **Muse Wonder/Spark** models. Plans **$5 Everyday / $15 High / $50 Power / $200 Maximum**, Wonder Full unlocks from Power. The product is still young, so it's worth watching its development and how developers actually adopt it. Only Meta models.

A separate issue is trust in Meta and code privacy: by default, subscriptions use **Contributor mode**, which allows Meta to use submitted content to train its models. You can turn this off in the settings by choosing Standard mode.

**xAI — Grok Build and Cursor**
https://docs.x.ai/build/overview
https://cursor.com/cli
https://docs.x.ai/x-subscription/overview
Elon Musk's company: the **Grok 4.7** model (the Fast variant only through harnesses) is available in the lightweight **Grok Build** CLI and the acquired **Cursor**. **The X Subscription** merged Grok, Cursor, and X into one subscription with a shared weekly pool. Plans **Free / Plus $8 / Premium $30 / Super $100 / Ultra $200**. On Free, Grok Build's limits are very tight — sometimes it can't even finish a single task. Also only the Grok model.

**Microsoft — GitHub Copilot**
https://microsoft.ai/models/mai-code-1-flash/
https://github.com/features/copilot/cli
https://github.com/features/copilot/plans
Microsoft is developing its own compact model **MAI-Code-1.1-Flash** (MoE 137B, 6.8B active). It is available in **GitHub Copilot** and VS Code. GitHub Copilot has its own terminal harness variant. Prices: Free $0 / **Pro $10** / **Pro+ $39** / **Max $100**. The free tier includes 2,000 completions per month with lightweight models. MAI-Code-1.1-Flash is also being optimized for **local** execution; Microsoft announced an experimental integration into Copilot CLI and other Microsoft clients for the end of October 2026.

In its early days GitHub Copilot got models only through its **partnership with OpenAI**; later Anthropic, Google, xAI, and Kimi K3 were added. They also tend to be conservative and don't rush to add new features until users of other harnesses react positively.

**China**

**Xiaomi — MiMo Code**
https://mimo.xiaomi.com/coder
https://mimo.mi.com/docs/en-US/tokenplan/subscription
The terminal **MiMo Code** harness is built as a fork of the popular OpenCode project for its own models **mimo-v2.6-pro** and **mimo-v2.6-flash**, with cross-session memory added. The repo has [issue 1230](https://github.com/XiaomiMiMo/MiMo-Code/issues/1230) asking Xiaomi to openly thank OpenCode's contributors — they kept the license but never mentioned the people who built the foundation.

MiMo Code inherited a weak spot from OpenCode in its **security model**: the `allow / ask / deny` permission system is not a full sandbox and doesn't guarantee the agent won't bypass restrictions by executing commands. On Windows, specifically, people found ways to get around file-access restrictions via PowerShell.

There's a shared **Token Plan** credit package for using Xiaomi models in supported tools, including OpenCode, Claude Code, and OpenClaw. Plans: **Lite $6 / Standard $16 / Pro $50 / Max $100**. There's no free way to try the mimo models. Like OpenCode, there's integration with the Models.dev model catalog.

**Alibaba — Qwen Code**
https://qwenlm.github.io/qwen-code-docs/en/users/quickstart/
https://docs.modelstudio.console.alibabacloud.com/en/model-studio/token-plan-overview
The terminal agentic **Qwen Code** harness, as I wrote earlier, was a fork of the old Gemini CLI v0.8.2 (they say so in the README), which then started evolving on its own and already has desktop and mobile apps. It supports **qwen3.8-max**, as well as the 3.7 / 3.6 lineups.

Free Qwen OAuth was discontinued on April 15, 2026. A separate Coding Plan Pro product at $50, which, according to Alibaba's documentation, is no longer available for purchase after the limited offer runs out. The international Token Plan is currently available only in the Singapore region. **Token Plan Personal:** Lite **$6** / Essential **$10** / Standard **$18** / Pro **$68** per month at promo prices. Alibaba's catalog contains more than just Qwen models.

**DeepSeek — DeepSeek Harness (dsh)**
https://github.com/deepseek-ai/deepseek-harness
https://deepseek.ai/pricing
**dsh** is an open-source project for building an agentic harness whose main principle is **"everything is a plugin"**: you can replace not only models and tools, but also memory, sessions, sandboxes, the agent's work loops, and the interface itself. It is built on the Cordis plugin core. There's a Web UI, headless launch, and several operating modes — from a minimal agent with a shell and file editor to a full coding agent with planning, subagents, and workflows. DeepSeek has **no subscription** plan — only pay-per-token with (off-)peak pricing. When registering in the harness, a new DeepSeek account may get a small number of free credits.

**Zhipu — ZCode**
https://zcode.z.ai/en
https://z.ai/subscribe#code-plans-container
**ZCode** is the Chinese company Z.ai's own agentic development environment (ADE), integrated with its **GLM-5.3** model. It is a desktop app for Windows, macOS, and Linux, **not a terminal CLI**. GLM Coding Plan works not only in ZCode: the subscription can be used in many compatible harnesses. Plans: **Lite $18 / Pro $80 / Max $168**. Only GLM models.

**Moonshot — Kimi Code**
https://www.kimi.com/code/
The **Kimi K3** model and the **Kimi Code** agentic harness (CLI, VS Code, Desktop). The old **Kimi CLI** was written in Python. On September 23, 2026, Moonshot archived it and replaced it with the new **Kimi Code CLI** — a different codebase, a redesigned interface, and distribution as a single binary. The new CLI is written in TypeScript, and its terminal interface is built on top of a separate **pi-tui** library. There's no free way to try the model.

Plans **Plus $19 / Pro $39 / Max $99 / Ultra $199**, previously named after musical tempos: Andante, Moderato, Allegretto, and Allegro — but the sales department apparently didn't appreciate it. Credits are shared across all Kimi services — Kimi Code, the chat agent, and Deep Research. The subscription includes *only* Kimi models, but in Kimi Code you can connect any other models via your own API keys.

**MiniMax — MiniMax Code**
https://github.com/MiniMax-AI/minimax-code
https://platform.minimax.io/subscribe/token-plan
For the **MiniMax M3** and **M3.1-Flash** models, the company is developing its own agentic harness **MiniMax Code** as an ecosystem with a desktop app, web interface, terminal CLI, and mobile apps for iOS and Android. The terminal agent is open source under the MIT license.

MiniMax Code can be connected directly to your MiniMax account. Token Plan: previously **Plus $22 / Max $55 / Ultra $132**, new names **Go / Explore / Build**. 50% off the first month. There are free quotas. The subscription includes *only* MiniMax models. The ability to add custom model providers via OpenAI- and Anthropic-compatible APIs is only available in paid subscriptions.

**Tencent — CodeBuddy Code**
https://www.codebuddy.ai/docs/cli/overview
https://www.codebuddy.ai/docs/ide/Account/pricing
Tencent is developing its own **Hy3 and Hy4** models and the agentic harness **CodeBuddy Code**. It is not tied exclusively to Tencent models. Subscription **Pro $10, Team $40 per user** per month, plus a Top-up Pack — a one-time purchase of additional credits available to active Pro and Team subscribers. In the end I couldn't figure out whether it's only their models or also GLM, Gemini, etc.

**Other countries**

**Mistral (France) — Vibe**
https://mistral.ai/solutions/coding/
https://mistral.ai/products/vibe/
https://mistral.ai/pricing/
It has its own model lines **Devstral**, **Large/Medium/Small**, the unique **Leanstral**, and the **Mistral Vibe** agentic CLI harness. The Vibe ecosystem also covers the web interface (formerly called Le Chat), mobile apps, and IDE plugins. The old Vibe variant can still be run via `--legacy-harness`. It's hard to tell whether this can be used for real work, because it looks like an unstable project.

The `Mistral Medium 3.5` and `devstral-small` models can be tried for free, but you can't turn off consent to use data for training. Full access is available in the **Pro $14.99 and Team $50 for two** subscriptions; extra usage can be paid as you go (PAYG). The company lags behind the US and China, so they added **GLM-5.3** as an alternative.

**JetBrains (Czechia) — Junie**
https://www.jetbrains.com/junie/
https://www.jetbrains.com/ai-ides/buy
JetBrains' own model line is called **Mellum**, where Mellum2.1 is an open MoE model with 12B parameters, 2.5B of them active (i.e., small and fast). But the **Junie Local** harness variant for local coding currently uses only a specially tuned **Qwen3.8-3.6-27B-blend**.

JetBrains' full coding agent **Junie** runs in the IDE, in the terminal, and in GitHub Actions. It supports models from OpenAI, Anthropic, Google, and xAI, as well as third-party providers and compatible local endpoints. JetBrains AI plans: **Free — $0 (3 AI credits) / Pro — $10 (10 credits) / Ultimate — $30 (35 credits)**. One AI credit corresponds to $1 of cloud-model usage cost.


*An important note on the impossibility of comparison. Because although most have $10/$20 plans, that doesn't mean they're the same in terms. There's no standard for how many tokens to include, and on top of that everyone has different models with different capabilities.*
