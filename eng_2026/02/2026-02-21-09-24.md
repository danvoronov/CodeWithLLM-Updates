https://opencode.ai/docs/windows-wsl 
If you use the desktop version on Windows, it is better to **run the backend** (server-side) **in WSL** (Windows Subsystem for Linux) — there are currently open issues regarding integration improvements, but WSL already provides the most stable result. It offers significantly better file system performance, full terminal support, and compatibility with development tools.
