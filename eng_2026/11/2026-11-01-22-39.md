Herdr now has a desktop app — no longer just "tmux for agents"

**Herdr — a runtime for coding agents**
https://herdr.dev/tui/
Herdr is a runtime for coding agents that doesn't just wrap Claude Code, Codex, OpenCode, or Pi — it owns their terminals. The classic Herdr isn't going away, but it's now a separate product with its own server: agents started in the TUI don't show up in the app, and vice versa.

https://herdr.dev/
On October 29, Herdr announced two things at once: the new **herdr-core** and a **native desktop** app built on it. Agents live in `herdr-core`, a small server on the machine, so closing the window or updating doesn't kill the work. Agents can control other agents. After a `herdr-core` restart, processes aren't restored — only the layout.

Herdr is interesting because it turns the UI into files and lets agents control each other. It's no longer "tmux with statuses" but an attempt to build a work environment an agent can rewrite for itself. Telemetry in releases is on by default (Settings → Privacy).

Layouts aren't themes but full windows with their own logic. **Herdr 98** ships in the box. The community shares its layouts: **Pasture** (agents as sheep; a blocked one jumps with a speech bubble), **Mission** (green mission control), **Board** (cards: needs you / working / done / idle), **Call**, **Threads**. Importantly, someone else's layout can read files, access the network, and run processes.

**Quick tour**
shows that the desktop is not just a pretty TUI but a construction kit. Light theme, importing old TUI settings, adding a file tree mod during setup, opening a space.

[https://www.youtube.com/watch?v=6GR75W2dRmU](https://www.youtube.com/watch?v=6GR75W2dRmU)

![YouTube Preview](https://img.youtube.com/vi/6GR75W2dRmU/sddefault.jpg)

The author shows that mods can be installed right away. You can ask Herdr to switch to tmux bindings. The author tells the agent: "split panel vertically and start two Codex agents; add another tab with two Claude agents" — the agent splits the pane, opens a tab, and starts the agents itself. Agents communicate through a bridge; the lead agent delegates to workers; you can sort by priority/space, drag panels, and split horizontally or vertically.

**Discussion**
https://news.ycombinator.com/item?id=50298436
A "harness for your harnesses" that doesn't look like vibe-coded slop. Convenient "everything is a pane": you can keep an SSH session in one pane and ask an agent in another to diagnose the system, and it doesn't pull your SSH keys into the harness; agents from different vendors can review each other; UI customization: "told it to add a feature, and it reloaded."

Criticism: TUI and app are fragmented, old sessions weren't picked up, keybindings are different; no built-in browser; on Windows there's no proper installer/uninstaller; some found the app didn't detect Claude Code or showed empty panes after a restart.
